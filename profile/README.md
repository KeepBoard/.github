## 🧩 KeepBoard HCM

KeepBoard is an open-source Human Capital Management (HCM) platform and ecosystem. We build modular services and tools that help teams manage people operations end-to-end while remaining self-hostable and cloud-ready.

### 🚀 What we build

- Core HCM services (employee records, org structure, roles, permissions)
- Workforce workflows (onboarding, time-off, approvals, notifications)
- Data platform and integrations (events, analytics, exports)
- Modern web apps for admins and employees

### 🛠️ Tech stack

- Backend: Spring Boot
- Messaging/Streaming: Kafka
- Database: PostgreSQL
- Frontend: React
- Platform: Docker, Kubernetes

### 🧱 Architecture principles

- Modular, service-oriented components with clear boundaries
- Event-driven by default; APIs for synchronous needs
- Infrastructure-as-code and container-first deployments
- Security, observability, and quality as first-class concerns

### 📂 Repositories in this org

You’ll find service backends, frontend apps, shared libraries, and infra tooling across the org. Start by checking pinned repositories on the organization page for the most active projects and roadmaps.

### 🤝 Contributing

We welcome contributions of all kinds—issues, discussions, docs, and code. If you’re unsure where to start:

1. Browse open issues labeled “good first issue” or “help wanted”.
2. Open a discussion or issue to propose ideas before large changes.
3. Follow conventional commits in PR titles for clear history.

Please ensure tests and linters pass locally before opening a PR.

### 🧪 Quality and code style

- Static analysis and code quality guidelines are available in `profile/Static-Analysis-and-Code-Quality-Guidelines.md`.
- Commit messages should follow the conventional commits spec.

### 🔐 Security

If you discover a security issue, please do not open a public issue. Report it privately via the organization’s security reporting channel (e.g., GitHub Security Advisories). We will triage and respond as quickly as possible.

### 💬 Community and support

- Use Discussions (if enabled) for questions and ideas.
